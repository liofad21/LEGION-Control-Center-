# Legion Control Center (Y700 Gen 3)

بديل لوحة الإعدادات السريعة على أندرويد، بتصميم Legion الأحمر + مساعدة ذكية بصوت بنت (Gemini).

## البناء
ارفع المشروع على GitHub ← Actions ← Build APK ← Artifacts.

## الإعداد على التابلت
1. ثبّت الـ APK وافتح التطبيق.
2. فعّل الصلاحيات من الشاشة الرئيسية (إمكانية الوصول، تعديل الإعدادات، عدم الإزعاج، قراءة الإشعارات، المايك).
3. اختياري: `adb shell pm grant com.legion.controlcenter android.permission.WRITE_SECURE_SETTINGS`
4. المساعدة: حط مفتاح Gemini API (مجاني من aistudio.google.com) واضغط حفظ.

## المساعدة
- الشخصية عايمة فوق أي تطبيق، اسحبها، وإضغط عليها للشات (كتابة أو مايك).
- بتنفّذ: سطوع، صوت، واي فاي/بلوتوث/...، معدل التحديث، أوضاع الأداء، ميديا، لقطة شاشة، فتح تطبيق، حالة الجهاز.
- الموديلات في `GeminiClient.kt` (`CHAT_MODEL`, `TTS_MODEL`, `VOICE`).
